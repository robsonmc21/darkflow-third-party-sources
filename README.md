# DarkFlow Studio — third-party sources / fontes de terceiros

This repository exists **only** to publish, free of charge, the source code and license texts of third-party software
distributed with DarkFlow Studio (developer brand: CoreFlow Group). It contains **no DarkFlow Studio code**.

Este repositório existe **somente** para disponibilizar gratuitamente o código-fonte e os textos de licença dos programas de
terceiros distribuídos com o DarkFlow Studio (marca desenvolvedora: CoreFlow Group). Ele **não contém código do DarkFlow Studio**.

Downloads are free and anonymous: no login, no DarkFlow Studio license, no payment.
Os downloads são gratuitos e anônimos: sem login, sem licença do DarkFlow Studio e sem pagamento.
